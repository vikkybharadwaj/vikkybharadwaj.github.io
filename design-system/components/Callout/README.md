A bordered note that flags a tip, warning or milestone inside instructional copy.

The border and title take the `tone`; the fill is that tone at 6%. Tone carries meaning: `green` for a win or milestone, `cyan` for a tip, `amber` for a warning, `purple` for a debugging step.

**You provide:** short `title` in capitals (it is set at 12px, 800), and body text as children; wrap emphasis in `<b>`.

- Do state the action in the first sentence.
- Don't stack more than two callouts in a row.
- Always pair the colour with the title word; colour alone must not carry the meaning.
