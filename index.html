About

Product and engineering, together.

I'm a product manager who works hands-on. On my current project, Tide, I've handled the product direction and specs as well as much of the implementation — the React Native app, AdonisJS services, the PostgreSQL data model, AWS infrastructure, and the Claude-based AI pipeline.

I'm especially interested in making AI features measurable — using evals (dimensions, fixtures, ground-truth, judge scoring) so quality is something you can track and improve rather than guess at. I also try to keep documentation as a living spec next to the code, so what's written stays in step with what's shipped.

FEATURED PROJECT

Tide — personal cash flow.

A mobile-first personal finance app built around one question: what's actually safe to spend? Behind it is a working system — an AI pipeline on AWS Bedrock + Claude, payday-aware Safe-to-Spend, bank sync through a provider-abstracted layer, a categorization engine that learns, and a living visual-docs site where each data flow doubles as the product spec.
