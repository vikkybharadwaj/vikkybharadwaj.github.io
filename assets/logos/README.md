Company logos for the experience section. Each file is shown unmodified, in its own colours, on a light plate (`.mark-plate` in `index.html`). Only transparent margins were trimmed and the images scaled to 96px high.

| File | Source | Notes |
| --- | --- | --- |
| `trustly.png`, `wayfair.png`, `ahold-delhaize.png`, `whirlpool.png` | Supplied by the site owner | Trademarks of their owners, shown to name former employers |
| `zillow.svg` | Simple Icons 13.21.0 (`icons/zillow.svg`) | CC0 1.0 for the artwork; Zillow's trademark. Icon only, so the page also shows the name as text |

To add or replace a logo, drop a PNG with a transparent background (or an SVG) here, then reference it in `index.html` the way the existing roles do, with `alt` set to the company name when the logo contains the name. Never redraw or approximate a mark.
