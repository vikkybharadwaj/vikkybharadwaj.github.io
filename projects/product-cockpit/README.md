# Product Cockpit — portfolio case study

A self-contained, static case study about building an **AI-native operating system for product decisions**. Customer first; engineering as the enabler.

Open `index.html` locally, or visit the GitHub Pages site for this repo. No build step, no dependencies — plain HTML + one CSS file.

- **`index.html`** — the overview (start here)
- **`docs/architecture.html`** — architecture deep-dive
- **`appendix.html`** — the artifacts: a generalized hook, policy, and skill, plus a worked example

All domain details are a neutral, fabricated stand-in; structural counts are real, and outcome figures are labelled illustrative.
